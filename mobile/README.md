# Kurye Sistemi Mobile

Bu uygulama Kurye, Restoran ve Admin panellerini tek mobil uygulamada role gore acar.

## Kurulum

```bash
cd mobile
npm install
cp .env.example .env
npm run start
```

## Notlar

- Giris endpointi: /auth/login
- Basarili giriste role gore panel acilir.
- Bu ilk asama iskelet surumdur.
